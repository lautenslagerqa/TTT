# Tic-Tac-Toe AI

A Java Tic-Tac-Toe game featuring a graphical interface and an AI opponent using the **Minimax algorithm**.

## Features

* Human vs. AI gameplay
* Java Swing graphical interface
* Minimax-based AI decision making
* Win, loss, and draw detection
* Object-oriented game architecture

## Technologies

* **Java**
* **Java Swing**
* **Minimax Algorithm**
* **Recursion**
* **Object-Oriented Programming**

## Project Structure

```text
TTT/
├── GUI.java    # Graphical interface
├── TTT.java    # Game logic and AI
└── .gitignore
```

## What I Learned

This project provided practical experience with **Java GUI development, recursion, algorithm design, and game-state management**. Implementing Minimax gave me experience applying a recursive decision-making algorithm to a complete interactive application.
